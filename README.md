# Лабораторные работы по pandas и EDA

В репозитории находятся две лабораторные работы на датасете Titanic.

## Лабораторная работа №1

Ручная предобработка и начальный анализ данных с помощью pandas:

- загрузка и изучение датасета;
- изменение структуры и типов данных;
- обработка дубликатов и пропусков;
- обработка выбросов;
- построение графиков;
- корреляционный анализ;
- группировка и агрегация;
- критерий хи-квадрат и точный критерий Фишера.

Основной файл: [`lab1_titanic.ipynb`](lab1_titanic.ipynb).

## Лабораторная работа №2

Автоматизированный EDA с помощью `ydata-profiling`:

- дефолтный отчёт;
- минимальная конфигурация;
- кастомная конфигурация;
- полная конфигурация с несколькими методами корреляции;
- сравнение времени генерации и размера HTML;
- сравнение автоматического и ручного анализа.

Основной файл: [`lab2/lab2_automated_eda.ipynb`](lab2/lab2_automated_eda.ipynb).

Готовые HTML-отчёты находятся в папке [`lab2/reports`](lab2/reports).

## Запуск лабораторной №1

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook lab1_titanic.ipynb
```

## Запуск лабораторной №2

```bash
cd lab2
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook lab2_automated_eda.ipynb
```

Оба ноутбука сохранены с выполненными ячейками и поясняющими комментариями.
