# Лабораторная работа: предобработка и анализ данных с pandas

Учебная работа по первичной обработке и анализу табличных данных в Python.  
В качестве исходных данных используется датасет о пассажирах **Titanic**.

## Цель работы

Освоить основные возможности библиотеки pandas: загрузку и изучение данных,
изменение структуры таблиц, обработку пропусков, дубликатов и выбросов,
визуализацию, группировку и проверку статистических зависимостей.

## Задание

Для выбранного датасета необходимо выполнить следующие действия:

1. Загрузить данные с помощью `pd.read_csv()`.
2. Изучить данные: `head`, `tail`, `info`, `dtypes`, `columns`, `describe`,
   `unique`, `value_counts`.
3. Изменить структуру датасета с помощью `melt`, `set_index`, `reset_index`,
   `drop`, `concat`, `join`, `merge`; при необходимости переименовать столбцы
   и индексы через `rename`. Преобразовать типы и категориальные признаки с
   помощью `astype`, `pd.Categorical`, `cat.codes`, `replace`,
   `pd.get_dummies`, `LabelEncoder`, `OneHotEncoder`. Применить `apply` и
   строковый аксессор `str`.
4. Найти и удалить дубликаты с помощью `duplicated` и `drop_duplicates`.
5. Найти пропущенные значения через `isnull`, затем удалить или заполнить их
   с помощью `dropna` и `fillna`.
6. Обработать выбросы с помощью `clip` и фильтрации `df[условие]`.
7. Визуализировать данные: `plot`, `boxplot`, `hist`, `sns.scatterplot`.
8. Рассчитать корреляции через `corr` и построить корреляционную матрицу.
9. Сгруппировать и агрегировать данные с помощью `groupby`, `agg` и
   `pd.pivot_table`.
10. Проверить наличие зависимостей между категориальными переменными с помощью
    таблиц сопряжённости, критерия χ² и точного критерия Фишера.

## Датасет

Используется демонстрационный датасет
[Titanic из репозитория seaborn-data](https://github.com/mwaskom/seaborn-data/blob/master/titanic.csv).

Исходная таблица содержит:

- 891 строку;
- 15 столбцов;
- числовые, строковые и логические признаки;
- сведения о возрасте и поле пассажиров, классе обслуживания, стоимости
  билета, порте посадки, составе семьи и выживаемости.

Пропуски присутствуют в столбцах `age`, `embarked`, `deck` и `embark_town`.

## Выполненная обработка

- Найдено 107 полных совпадений строк. Они удалены в учебной рабочей копии
  таблицы. Поскольку в датасете нет уникального идентификатора пассажира,
  одинаковые строки теоретически могут описывать разных людей — это ограничение
  учтено в работе.
- Столбец `deck` удалён из-за большого количества пропусков.
- Пропущенный возраст заполнен медианой внутри групп пола и класса билета.
- Пропуски порта посадки заполнены наиболее частым значением.
- Выбросы стоимости билета определены методом межквартильного размаха (IQR) и
  ограничены с помощью `clip`, чтобы не удалять наблюдения из основной рабочей
  таблицы.
- Для категориальных признаков продемонстрированы разные способы кодирования.
- Построены диаграммы распределений, диаграмма размаха, точечный график и
  корреляционная матрица.

## Основные результаты

После удаления полных совпадений рабочая таблица содержит 784 строки.
Метод IQR обнаружил 102 выброса стоимости билета в этой таблице.

Для проверки связи между полом пассажира и выживаемостью использованы два
статистических теста:

- критерий χ² Пирсона: `χ² = 206.400`, `p-value ≈ 8.38 × 10⁻⁴⁷`;
- точный критерий Фишера: `p-value ≈ 2.84 × 10⁻⁴⁸`.

При уровне значимости 0,05 нулевая гипотеза о независимости признаков
отвергается: в исследуемой выборке между полом и выживаемостью обнаружена
статистически значимая связь. Такая зависимость сама по себе не доказывает
причинно-следственную связь.
